# Siyāq Forge
Shell: bottom navigation (Projects / Tools / Settings). Editor tools grouped in 5 categories (FlowRow, wraps on any width).
Responsive: panel heights, editor font, gutter and min widths derive from the current screen size.
Core: .sforge (SHA-256), multi-tab editor, highlight, search/replace, undo/redo, completion, formatter, auto-indent/auto-close,
goto-line, rename, diagnostics, dependency graph, plugins (sandboxed permissions), pipeline tasks, local web preview,
GitHub Actions cloud build -> download -> install, toolchain manager + self-test.
Build this app: push to GitHub -> Actions -> artifact SiyaqForge-debug.
